# Security awareness training

## Overview

Security awareness training is an important measure to improve the overall level of security in the organization.

## Training objectives

### 1. Knowledge enhancement

**Target:**
- Understanding security threats
- Identification of security risks
- We're on guard.
- Understanding security policies

### 2. Behavioural change

**Target:**
- To be safe.
- Compliance with safety norms
- Active reporting of incidents
- Participation in security activities

### 3. Cultural formation

**Target:**
- Building a culture of security
- Increased security awareness
- Promoting security collaboration
- Continuous Improvement

## Training content

### 1. Basic security

**Contents:**
- Password secure.
- Account security
- Device Security
- Network Security

**Password secure:**
- Use strong passwords
- Password does not re-use
- Enable multifactor authentication
- Change passwords on a regular basis

**Account secure:**
- Protect account information
- Do not share accounts
- Timely write-off accounts
- Monitor account activity

### 2. Mail security

**Contents:**
- Identification of fishing e-mails
- Handle suspicious mail.
- Attachment secure.
- Link secure

**Fishing e-mail recognition:**
- Check Sender
- Check Links
- Check Attachments
- Check Contents

**Processing of suspicious mail:**
- Do Not Click Link
- Do Not Open Attachment
- Report to the security team.
- Delete the email

### 3. Social engineering

**Contents:**
- Identification of social engineering
- Preventive social engineering
- Reporting suspicious behaviour

**Common means:**
- Fake identity.
- Emergencies
- Authoritative requirements
- Stimulation of interests

**Preventive measures:**
- Verify the identity
- I don't believe it.
- Report suspicious.
- Compliance process

### 4. Data Security

**Contents:**
- Data disaggregation
- Data protection
- Data Sharing
- Data destruction

**Data protection:**
- Encrypt sensitive data
- Secure Storage
- Safe transmission.
- Access Control

**Data sharing:**
- Minimize Sharing
- Use of secure channels
- Validate Receiver
- Record Sharing

### 5. Physical security

**Contents:**
- Device Security
- Office environment
- Visitors management
- Emergency response

**Equipment security:**
- Lock Screen
- Protective equipment
- Secure Storage
- Timely reporting of loss

## Training methodology

### 1. Online training

**Strengths:**
- Flexibility
- Reusable learning
- Lower cost
- Easy to track.

**Implementation:**
- Use LMS platform
- Production of training content
- Set the learning path
- Tracking learning progress

### 2. Face-to-face training

**Strengths:**
- Interactively strong
- Instant feedback
- In-depth discussion
- Relationship-building

**Implementation:**
- Regular Training
- Panel discussions
- Case analysis
- Practice

### 3. Simulation exercise

**Strengths:**
- Real scene.
- Practice
- Test Effect
- Enhancing capacity

**Implementation:**
- Fishing e-mail exercises
- Social engineering exercises
- Emergency response drill
- Security incident drill
